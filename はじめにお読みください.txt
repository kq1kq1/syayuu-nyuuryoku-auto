============================================================
 社有物件自動入力Bot　使い方
============================================================

このフォルダだけで動きます。
Python のインストールもインターネット接続も必要ありません。


============================================================
 １．最初の１回だけやること
============================================================

【1-1】zip のブロックを解除する

  メールや Teams で受け取った zip は、Windows が「他のPCから来た
  ファイル」として警告を出すことがあります。展開する前に解除して
  ください。

    zip を右クリック →「プロパティ」
      → 下のほうにある「セキュリティ:」の
        「許可する」にチェック → OK

  ※ これをやらずに展開すると、bat をダブルクリックしたときに
     「WindowsによってPCが保護されました」と出ることがあります。
     出てしまった場合は「詳細情報」→「実行」で進めます。


【1-2】デスクトップに展開する

  zip を右クリック →「すべて展開」→ デスクトップを選ぶ。

  ※ Dropbox / OneDrive の中には置かないでください。
     同期がファイルをロックして動かなくなることがあります。


【1-3】Google Chrome があることを確認する

  このツールは Chrome を操作します。
  Microsoft Edge では動きません。


【1-4】４つのサイトにログインする　★ここが一番大事★

  「1.最初にダブルクリック(ブラウザが開く).bat」をダブルクリック
  すると、いつもとは別の専用 Chrome が開き、４つのサイトの
  ログイン画面が並びます。

      ・スカイヤーズ　　（sys.arcs.jp）
      ・ピタットクラウド（pitat-cloud.com）
      ・SUUMO　　　　　 （manager.suumo.jp）
      ・ホームズ　　　　（homes.co.jp）

  この４つすべてに、手でログインしてください。

  ※ いつも使っている Chrome とは別のプロファイルなので、
     ログイン情報は引き継がれません。最初は必ず空です。
  ※ 一度ログインすれば保存されるので、次回からは不要です。


============================================================
 ２．毎回の使い方
============================================================

【2-1】「1.最初にダブルクリック(ブラウザが開く).bat」

    → Chrome が開きます。


【2-2】入力したい物件の編集ページを開く

    Chrome の中で、入力したいサイトの
    「その物件の編集ページ」を開いておいてください。

    タブはいくつ開いていても大丈夫です。
    アプリが自分で正しいタブを探します。

    ※ ピタクラだけは、URL に「/edit」が含まれる
       編集ページを開いてください。


【2-3】「2.次にダブルクリック(自動入力アプリが起動する).bat」

    → アプリの画面が出ます。
    → 最初に「物件情報を入力してください」と聞かれます。

         建築確認番号 … 中古など不要なときは空欄でOK
         物件価格（万円）

    ※ 順番を逆にすると「Chrome接続エラー」になります。
       その場合は 2-1 からやり直してください。


【2-4】物件タイプを選ぶ

    「新築」か「中古」を選びます。


【2-5】写真フォルダ（中古で撮影写真を使うときだけ）

    「参照...」でフォルダを選ぶ
      →「連番リネーム（撮影順）」を押す

    これだけです。Excel のファイル名の列は空白でかまいません。


【2-6】入力したいサイトのボタンを押す

      ・スーモに入力する
      ・ホームズに入力する
      ・ピタクラに入力する
      ・スカイヤーズに入力する

    下の「ログ」欄に進み具合が出ます。


【2-7】結果を目で確認してから、自分で保存する　★重要★

    このツールは保存しません。
    入力された内容を必ず確認してから、
    サイト側の保存ボタンを押してください。


【2-8】次の物件へ

    「次の物件へ（情報をリセット）」を押すと、
    建築確認番号と物件価格を入れ直せます。


============================================================
 ３．Excel と写真について
============================================================

【Excel】

  フォルダの中の

      社有入力テンプレート.xlsx

  が入力データです。物件ごとにこれを編集してください。

  ※ ファイル名は変えないでください。アプリが名前で探しています。
  ※ 別の場所に移動しないでください。bat と同じフォルダに置きます。
  ※ 入力を実行するときは Excel を閉じておいてください。
     開いたままだと書き込みエラーになります。


【写真】

  フォルダの中に、こういう形で写真を置きます。

      物件写真\
        ├ 同仕様モデルハウス\     ← 新築の既定フォルダ
        └ ホームズ写真\           ← ホームズ用


============================================================
 ４．うまく動かないとき
============================================================

■ ダブルクリックしても何も起きない

    黒い画面にエラーが出て止まっているはずです。
    画面を閉じずに、その内容を担当者に伝えてください。


■「Chrome接続エラー」と出る

    ・「1.最初に...」を実行していない
    ・専用 Chrome を閉じてしまった
    このどちらかです。2-1 からやり直してください。


■ ログイン画面のまま何も入力されない

    そのサイトにまだログインしていません。
    1-4 を見て、手でログインしてください。


■「ERROR: Google Chrome was not found」と出る

    Chrome が入っていません。Chrome をインストールしてください。
    Edge では動きません。


■「no Python runtime found」と出る

    zip の展開が途中で終わっています。
    フォルダの中に「python」というフォルダがあるか確認して、
    無ければ zip をもう一度展開してください。


■ Chrome は開くけどサイトが出てこない

    フォルダの中の「urls.txt」が無い状態です。
    メモ帳が開いたら、担当者に聞いて設定してもらってください。


■ Excel の書き込みでエラーになる

    Excel でファイルを開いたままだと保存できません。
    Excel を閉じてから、もう一度実行してください。
